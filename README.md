# Атлас философии

Интерактивный образовательный музей на русском языке: 24 философа, 5 эпох, 6 вопросов, 72 идеи и связи между мыслителями.

## Запуск

Требуется Node.js 20.9+ (проект проверяется на Node.js 24).

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Для production-сборки:

```bash
npm run check:data
npm run typecheck
npm run build
npm start
```

Сборка находится в `out/`, её можно разместить на статическом хостинге. `npm start` обслуживает её на http://localhost:3000, порт изменяется через `PORT`.

## Архитектура

- Next.js App Router, React и TypeScript; статический экспорт без серверной базы и внешних API во время работы сайта.
- Tailwind CSS 4, собственные CSS variables для светлой/тёмной темы и адаптивных layouts.
- Motion for React: переходы и появление элементов с поддержкой reduced motion.
- `src/components/Atlas.tsx`: главная, каталог, детали мыслителя, карта, хронология и сравнение. Навигация через hash сохраняет ссылки и работу кнопки «Назад» на статическом хостинге.
- `src/components/EducationalLab.tsx`: шесть авторских дилемм и ответы для размышления.
- `src/data/types.ts`: типизированная схема, эпохи, вопросы и типы связей.
- `src/data/philosophers.ts`: расширяемая коллекция мыслителей, идеи, произведения, источники и связи.
- `src/data/portraits.ts`, `public/portraits/`: локальные изображения и происхождение портретов.
- `scripts/check-data.mjs`: проверка целостности контента; `QA_REPORT.md`: результаты проверок.

## Редакционные принципы

Биографические сведения отделены от простых объяснений идей и современных учебных интерпретаций. В сравнении представлены интерпретации взглядов применительно к современным вопросам, а не цитаты. Приблизительные и спорные даты обозначены в карточках. Связи «сходство» и «различие» не утверждают исторического знакомства или влияния.

У каждой записи есть ссылки на справочные источники, преимущественно Stanford Encyclopedia of Philosophy и Internet Encyclopedia of Philosophy. Точные цитаты не используются. Изображения взяты из Wikimedia; авторы, лицензии и страницы оригиналов сохранены в `public/portraits/attribution.json`. Исторические изображения не всегда являются прижизненными достоверными портретами.

## Расширение

Добавьте объект `Philosopher` в `philosophers.ts`, укажите темы, позиции, источники и существующие `targetId` связей. При добавлении изображения дополните `portraits.ts` и сведения об атрибуции. Затем выполните проверки и сборку. Бэкенд для чтения контента не требуется.

## Интерактивная страница Платона

Откройте `/philosophers/plato/` или существующий маршрут `/#philosopher/plato`. Страница продолжает прежний Atlas: общий header/footer, светлая/тёмная тема, избранное и каталог сохраняются.

Реализованы пять раскрывающихся глав с локальными художественными фонами и crossfade, пять идей с собственными темами и быстрым показом всего текста, пять книжных вкладок, восемь разговоров с выбором ответа и React Flow карта с фильтрами, направленными связями и доступным списком. Тексты, источники, связи и темы отделены от JSX. Голос Платона — современная художественная реконструкция.

```sh
npm ci
npm run typecheck
npm run check:data
npm run check:plato
npm run test:plato
npm run build
node scripts/check-plato.mjs --build
npm start
```

После `npm start` страница доступна по адресу `http://localhost:3000/philosophers/plato/`.

- `src/components/plato/PlatoPage.tsx` — секции страницы, accordion, диалоги и книги; принимает типизированный `profile` (по умолчанию Платон).
- `src/components/plato/PhilosophyConnectionsMap.tsx` — React Flow, легенда, фильтры, клавиатурное управление и список связей.
- `src/data/plato-types.ts`, `plato.ts`, `plato-narrative.ts` — модель, исторические данные и разговорный сценарий.
- `public/plato/` — пять WebP-фонов.
- `docs/plato-content.md` — добавление нового философа; `docs/plato-assets.md` — происхождение иллюстраций; `docs/plato-qa.md` — результаты и ограничения проверки.

Первоначально версия подготовлена из исходного архива `philosophy-atlas.zip`. После открытия доступа изменения проверены командой `git apply --check` на актуальной ветке `main` репозитория `diofiveal/philosofy_atlas` и перенесены в `feat/plato-interactive`. Generated `out/` пересоздаётся командой сборки.

## Сократ: тот же интерфейс, отдельный профиль

Маршруты `/philosophers/socrates/` и `/#philosopher/socrates`. Содержимое — `src/data/socrates.ts` и `socrates-narrative.ts`; общий UI остаётся в `components/plato`, без второй копии компонентов. Раздел «Что обо мне написали» явно называет авторов и различает диалоги, воспоминания и комедийную сатиру. Карта различает личное общение и направленное влияние.

`npm run check:profiles` проверяет данные обеих страниц, `npm run test:profiles` — их интерактивность в обычном и reduced-motion режимах и сброс состояния при смене философа. После `npm run build` запустите `node scripts/check-plato.mjs --build` для проверки обоих экспортированных маршрутов. Порядок добавления следующих профилей описан в `PHILOSOPHER_PAGE_TEMPLATE.md`, границы QA — в `docs/socrates-qa.md`.

Чтение удалённого репозитория доступно; запись ранее отклонена подключением GitHub (403). Локальное наличие изменений не означает их публикацию или отправку на GitHub.
