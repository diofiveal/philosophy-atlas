# Отчёт проверки «Атласа философии»

Статус: данные, TypeScript, production-сборка и браузерные smoke-проверки — PASS. Публикация Site заблокирована внешним сервисом.

## Проверки данных

`npm run check:data` — PASS.

- 24 философа, 72 объяснения идей, 44 библиографические записи, 6 тем и 144 позиции для сравнения.
- 31 связь указывает на существующих мыслителей; нет ссылок на себя.
- 27 ссылок на источники имеют корректный HTTPS-адрес.
- Проверены уникальность ID, обязательные поля, эпохи, школы, темы, произведения и типы связей.
- Неизвестные даты допускаются только как пара `null/null` с явной оговоркой в поле `dates`; Лао-цзы не получает вымышленной даты.
- Произведения о Сократе обозначены как свидетельства Платона и Ксенофонта.

Проверка структуры не подтверждает доступность внешних страниц или каждую историческую интерпретацию. Источники и редакционную проверку готовил исследователь.

## Обзор исходного кода

Обработчики присутствуют для каталога, комбинируемых фильтров, сброса, пустой выдачи, избранного, переходов, карты и масштаба, выбора эпохи, сравнения, темы оформления и образовательных сценариев. Шесть авторских сценариев имеют по три варианта и обратную связь; идеи философов явно обозначены как современные учебные интерпретации.

Формы имеют доступные имена; основные действия используют нативные кнопки и select; выбранные состояния обозначены через `aria-pressed`; карта дополнена текстовым списком связей. Есть `useReducedMotion`, CSS media query и мобильные компоновки образовательного раздела.

## Исправлено по результатам проверки

1. Ссылка пропуска навигации теперь переводит фокус на main без изменения hash-маршрута.
2. Ссылка на сведения об изображениях исправлена на `/portraits/attribution.json`.
3. Даты Лао-цзы сохраняются как неизвестные; сортировка учитывает `null`, хронология выводит «Дата неизвестна» и объясняет положение записи.
4. Вопросы получили один h1 страницы; заголовок образовательного компонента заменён на h2.
5. Минимальные области нажатия компактных icon/save/zoom controls и select увеличены до 44 px.
6. Вертикальная плотность карты снижена: высота не меньше 960 px, уменьшение масштаба не сокращает расстояние между узлами.

`npm run typecheck` — PASS после исправлений. Повторный `npm run check:data` — PASS: 24 философа, 72 идеи, 6 тем, 31 связь, 27 источников.

## Production-сборка и браузерные проверки

`npm run build` — PASS, Next.js 16.4.5, статический экспорт в `out/`. Финальная сборка включает исправления после QA.

Проверено в браузере на production-экспорте:

- Главная страница, портреты и переходы между всеми семью разделами.
- Поиск «кант» → один результат; несовместимый фильтр эпохи → пустая выдача.
- Стоицизм + тема счастья → два мыслителя; сброс фильтров.
- Сохранение Эпиктета, фильтр избранного и сохранение состояния после переходов/перезагрузки; тестовое избранное затем очищено.
- Страница Эпиктета: биография, три идеи, произведения, связь и ссылки на источники.
- Карта: выбор Платона → три связи; увеличение масштаба → 110%; фильтр темы сознания.
- Хронология: средневековая эпоха → Ибн Сина, Ибн Рушд, Фома Аквинский.
- Лаборатория: сценарий о счастье, выбор ответа, разбор, три интерпретации, переход к сравнению.
- Сравнение: смена вопроса и второго философа обновляет позиции.
- Светлая и тёмная палитры; сохранение темы.
- Мобильная ширина 390 px проверена в iframe с реальным узким layout viewport: меню раскрывается и закрывается после перехода, поиск работает, сравнение переходит в одну колонку. Ширина содержимого совпадает с доступной шириной (375 px с учётом полосы прокрутки).

Дополнительно исправлено при браузерной проверке: слияние строк мобильного hero и горизонтальный overflow; мелкий текст на мобильном; поиск расширен на позиции и названия тем; е/ё нормализуются; приблизительные годы в хронологии маркируются; контент видим при SSR до hydration.

Ошибок приложения в просмотренных console-сообщениях не обнаружено. Наблюдались отдельные ошибки расширения облачного браузера о передаче метаданных; они не относятся к коду сайта.

## Ограничения проверки и публикации

Это smoke-проверка, не полная сертификация WCAG и не проверка всех сочетаний 24×24×6. Мобильная проверка проведена в узком iframe, не на физическом смартфоне. Доступность оценена по семантике, подписям, фокусу, touch-зонам и reduced-motion; полная проверка скринридером не проводилась.

В dev-режиме managed-предпросмотра Work не завершалась hydration. Для браузерного QA использован поддерживаемый статический предпросмотр `out/`. Локальная команда `npm run dev` сохранена для Next.js; production-версия не зависит от dev-сервера.

Сервис Sites дважды вернул `Sites backfill is in progress in this destination` при попытке регистрации. Project ID и адрес опубликованного Site не получены; успешная публикация не заявляется. Доступен браузерный предпросмотр собранного приложения и полный локальный пакет.
