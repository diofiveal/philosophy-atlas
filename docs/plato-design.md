# Страница Платона: визуальная и интерактивная спецификация

Страница расширяет существующий «Атлас философии», а не вводит отдельную дизайн-систему. Аудит выполнен по `src/components/Atlas.tsx`, `src/app/globals.css`, `src/data/types.ts`, `package.json` и `public/portraits/`.

## Существующая основа

| --- | --- |
| Бумага | `var(--paper)`; светлая тема `#f4f1e8`, тёмная `#171b17` |
| Основной текст | `var(--ink)`; `#20231f` / `#f3f0e6` |
| Вторичный текст | `var(--muted)`; `#74766d` / `#acb0a3` |
| Акцент | `var(--accent)`, `#dfff62` |
| Разделители | `var(--line)`; `#d7d9ce` / `#3b4338` |
| Поверхности | `var(--panel)`; `#eeeee5` / `#222820` |
| Типографика | Georgia / Times New Roman для заголовков, Arial / Helvetica для текста |
| Геометрия | Тонкие рамки, радиус около 3 px, широкие поля, небольшие индексные номера |
| Иллюстрации | Чёрно-белый античный бюст, приглушённые естественные цвета фона |

`motion/react` уже установлен; использовать его повторно. Общая карта сейчас написана вручную: для новой персональной карты добавить `@xyflow/react`, не переписывая глобальную карту сайта. Основной интерфейс использует hash-навигацию; сохранить вход `#philosopher/plato`, даже если дополнительно появится отдельный App Router URL.

## Композиция

1. Существующая общая шапка.
2. Ссылка в каталог, затем hero: индекс «Афины / IV век до н. э.», крупное имя, разговорное приглашение, даты, бюст и две ясные команды «Послушать мою историю» / «Перейти к идеям».
3. Компактное пояснение: рассказ от первого лица — современная художественная интерпретация, не исторические цитаты.
4. Локальная навигация: «Моя жизнь», «Мои идеи», «Мои книги», «Мои собеседники», «Источники».
5. Биография в пяти главах.
6. Пять идей с вопросами и тремя отдельными дилеммами.
7. Пять произведений.
8. Интерактивная карта и доступный список связей.
9. Источники и оговорки исторической достоверности.

Контейнер наследует `--max` и `--gutter` проекта. На широком экране текстовые блоки ограничить 58–66ch; полная ширина допустима для hero и графа. Отступы между разделами 64–80 px, на мобильном 40–48 px. Не уменьшать основной текст ниже 16 px для длинного чтения.

## Фоновая атмосфера

В пределах страницы Платона расположить два абсолютно/фиксированно позиционированных декоративных слоя с `pointer-events:none` и `aria-hidden`. Одновременно видны максимум предыдущая и текущая сцены; crossfade 650–900 ms. Смена темы не меняет `documentElement.dataset.theme`: выбранная пользователем светлая/тёмная тема сохраняется.

Текст читается на почти непрозрачной бумажной или графитовой поверхности. Сам пейзаж виден прежде всего в полях, вокруг заголовков и сквозь мягкий градиент. Блики и зерно слабые; не перекрывать ими буквы. Для кадра использовать `object-fit:cover`, отдельный `object-position` из данных и запасной цвет при недоступной картинке.

| Глава | Изображение / сюжет | Свет и акцент |
| --- | --- | --- |
| Детство | Афинская улица, рынок, дальний Акрополь | Утренний пыльный бежевый |
| Сократ | Небольшая беседующая группа на площади | Сдержанный серо-оливковый, более тёмные края |
| Академия | Сад, колоннада, ученики, свитки | Мягкий шалфейный / бумажный |
| Сиракузы | Дворцовая терраса над греческой гаванью | Выцветший морской синий и камень |
| Последние годы | Рукописи, библиотека, закатный свет | Коричневый / старое золото |

В исходном репозитории есть только портреты; новые сцены должны храниться локально и иметь единый художественный стиль. Предлагаемые пути: `/plato/athens.webp`, `/plato/socrates.webp`, `/plato/academy.webp`, `/plato/syracuse.webp`, `/plato/library.webp`. Это живописные современные интерпретации, а не изображения, документирующие реальные события. Загружать первую нужную сцену заранее, последующие — при обращении; не декодировать десять полноразмерных изображений одновременно.

## Биография

Каждая карточка: номер 01–05, период, заголовок, одно предложение-анонс и значок плюс/минус. Весь заголовок — один `<button>` внутри `h3`, `aria-expanded` и `aria-controls` указывают на соответствующую панель. Допускаются состояния «все закрыты» и «одна открыта»; никогда две открытые главы.

Открытая карточка получает тонкую акцентную границу/полосу и лаймовый индекс. Панель высотой `auto`, без внутренней прокрутки; текст не обрезается. Уточнения «дата приблизительна», «позднее предание», «историческая реконструкция» выводятся рядом с соответствующим местом, источники — в конце главы.

Переключение: предыдущая панель закрывается за 220–300 ms; новая раскрывается за 300–400 ms, текст проявляется со сдвигом максимум 6 px. Не применять `AnimatePresence mode="wait"` ко всему списку: быстрое переключение должно реагировать на последнее действие. На телефоне сохраняется вертикальный список; в конце открытого текста — «Предыдущая глава» и «Следующая глава» с минимум 44 px для нажатия. Фокус при смене из этих кнопок переводится к новому заголовку; не прокручивать страницу от каждого простого раскрытия.

## Идеи и разговор

Закрытые прямоугольные карточки: индекс, небольшой декоративный символ, название, интригующая фраза, явная команда раскрытия. На desktop — две колонки, на mobile — одна. Полный рассказ раскрывается inline; длинный текст не помещать в узкий модальный диалог. Порядок визуальных элементов соответствует DOM.

| Идея | Визуальное состояние |
| --- | --- |
| Пещера | Графитовый фон, мягкие диагональные тени, янтарный источник света, тёплый бумажный текст |
| Идеи | Бумага, прозрачные геометрические контуры и слабое свечение |
| Государство | Выцветшие колонны / архитектурные линии, каменный серый |
| Душа | Три тонкие пересекающиеся дуги/области, спокойный оливковый |
| Любовь | Тёплый вечерний градиент, античный силуэт, приглушённая терракота |

Декоративная геометрия реализуется CSS/SVG, не требует тяжёлых фоновых видео. Цвета и сцены берутся из конфигурации темы. Каждый рассказ: ситуация → проблема → позиция → вопрос → варианты разговора. Абзацы проявляются последовательными смысловыми блоками с интервалом 80–120 ms, вся последовательность около секунды. Кнопка «Показать весь текст» доступна сразу и убирает задержки. В режиме reduced motion весь текст виден сразу.

Вопросы — обычные кнопки с вариантами, не тест с красными/зелёными оценками. После выбора видна реплика Платона, выбранный вариант выделен акцентной полосой; доступны «Попробовать другой ответ» и продолжение. Реакцию объявлять через короткий `aria-live="polite"` контейнер; не назначать live всему длинному рассказу.

Три дилеммы оформляются как отдельные сцены: «Выйти из пещеры», «Кому доверить город?», «Откуда берётся красота?». Вопросы не должны предполагать единственный правильный ответ. Группу вариантов подписать видимым вопросом.

## Мои книги

Пять карточек-книг: тонкий корешок, типографическое название, номер, тема. Цветовая основа — бумага/графит, один лаймовый акцент. На широком экране 5 карточек могут стоять в ряд только при достаточной ширине, иначе 3+2; mobile — 2 колонки или одна при ширине до 380 px. Карточки не превращать в горизонтальную карусель с обязательными жестами.

Hover: подъём 4–6 px за 180 ms; focus получает тот же смысловой эффект и явную рамку. По нажатию открывается общий информационный блок под галереей: личная рекомендация, содержание, основные вопросы, что читать, источник/фрагмент текста. При смене книги — opacity 180–240 ms. Выбранную книгу отмечать доступным `aria-pressed`; декоративный 3D-поворот не нужен для чтения.

## Карта собеседников

Платон — центральный узел. Вокруг: Сократ, Аристотель, Парменид, пифагорейская традиция, Плотин. Не выдавать последние три связи за личные встречи.

| Связь | Линия | Подпись |
| --- | --- | --- |
| Учитель → ученик | Сплошная | «Учительство» |
| Интеллектуальное влияние | Длинный пунктир | «Влияние идей» |
| Критика | Короткий пунктир | «Разногласия» |
| Позднейшее развитие | Штрих-точка | «Развитие учения» |

Стиль линии и текстовая легенда обязательны: цвет не единственный носитель смысла. Направления стрелок соответствуют данным. Две связи Платон → Аристотель и Аристотель → Платон допустимы, если показывают учительство и критику отдельно.

Desktop: карта около 540 px высотой, справа/ниже подробная карточка выбранной связи. Фильтр по типу, масштаб −/+, «Показать всю карту», pan перетаскиванием, колёсико масштабирует только в пределах карты и без неожиданного захвата прокрутки страницы. Узлы имеют доступное имя и короткую подсказку по hover/focus; на click раскрывается подробность, переход к философу — отдельная команда.

Mobile: по умолчанию текстовые карточки связей; команда «Открыть карту» переключает к компактному графу высотой 400–460 px. Карта не должна расширять viewport; никакого `min-width:820px`, унаследованного от общей карты. Кнопки масштаба минимум 44×44 px. Для отсутствующей страницы (Плотин/Парменид) показывать саму информацию и отсутствие ссылки, без фиктивной навигации. Доступный список связей сохраняется независимо от графа.

## Проверяемые состояния

- Светлая и тёмная темы: длинный текст читается при каждой фоновой сцене.
- Все главы закрыты; каждая открыта; быстро 01→05→02; переход с последней на предыдущую.
- Все идеи закрыты; открытие/закрытие каждой; пропуск проявления текста.
- Выбор каждого ответа и повторный выбор без отметок «ошибка».
- Переключение всех книг мышью и клавиатурой.
- Все фильтры графа, пустой набор, fit view после фильтрации, pan/zoom, мобильный список.
- 1440, 1024, 768, 390 и 360 px: без горизонтального переполнения, 16 px основной текст.
- Tab/Shift+Tab, Enter/Space для кнопок, видимый фокус; заголовки не теряются после обновления DOM.
- `prefers-reduced-motion:reduce`: убрать параллакс, задержки, hover transform и плавный автоскролл, сохранить полную функциональность.

Все новые стили изолируются классом/модулем страницы Платона. Глобальные CSS-токены, шапка, каталог и страницы остальных философов сохраняются.
