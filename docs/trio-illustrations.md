# Иллюстрации новых биографий

Для Аристотеля, Эпикура и Марка Аврелия созданы по пять оригинальных изображений средствами OpenAI Image Generation (ноябрь 2026). Файлы `public/{aristotle,epicurus,marcus-aurelius}/{1..5}.webp` подключены через конфигурации тем в данных профилей.

Единый стиль: плоский бумажный коллаж, геометрические силуэты без портретного сходства, пергаментный, оливковый и графитовый цвета. Это современные художественные реконструкции, а не археологические документы или изображения установленных сцен. Изображения не заимствованы из сторонних коллекций. Исходники оптимизированы для веба, ширина не более 1440 px.

- Аристотель: Стагира, Академия, наблюдения природы, македонское обучение, Ликей.
- Эпикур: Самос, странствия, Сад, дружеская трапеза, последние годы.
- Марк Аврелий: детство в Риме, обучение, совместное правление, пограничный лагерь, последние годы.
